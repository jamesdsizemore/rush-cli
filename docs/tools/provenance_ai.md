# AI Code Provenance Auditor (`rush provenance-ai`)

## Overview
`rush provenance-ai` audits AI code attribution and provenance across Git commit history. It inspects commit trailers (`Co-authored-by:`, `Generated-by:`, `Model:`, `Agent:`, `AI-Assisted:`), checks for repository shallow clones, calculates 30/60/90-day code line survival rates via `git blame --line-porcelain`, and correlates fix commits with AI-attributed changes.

## Classification
- **Category**: `workflow`
- **Maturity**: `real_adapter`
- **Tool Name**: `provenance-ai`
- **FastMCP Tool**: `rush_provenance_ai`

## Capabilities
1. **Commit Trailer Attribution**: Parses standard Git trailers to classify commits into:
   - `ai_generated`: Commits created directly by AI agents or marked with `Generated-by:` / `Agent:`.
   - `ai_assisted`: Commits with `Co-authored-by:` naming an AI entity, or tagged with `Model:` / `AI-Assisted:`.
   - `human`: Commits authored solely by human contributors with no AI trailers.
2. **Dual-Check Shallow History Detection**: Inspects `.git/shallow` and Git repository depth via `git rev-parse --is-shallow-repository`. If the clone is shallow, emits a warning finding indicating that historical provenance is truncated.
3. **Line Survival Analysis**: Uses `git blame --line-porcelain` against current `HEAD` to determine surviving lines authored in AI-generated vs AI-assisted vs human commits across 30-day, 60-day, and 90-day horizons.
4. **Defect Correlation**: Identifies bugfix commits (`fix:`, `bug:`, `revert:`) modifying lines previously touched by AI commits, computing an empirical defect correlation rate.

## CLI Usage

### Basic Audit
```bash
rush provenance-ai .
```

### JSON Wire Format
```bash
rush provenance-ai . --json
```
