# Rush tutorials

These lessons are ordered by adoption stage. Each one states its outcome, prerequisites, exact commands, expected result, and next step.

1. [Your first 10 minutes](tutorials/first-10-minutes.md) — install confidence and a first deterministic review.
2. [Python project](tutorials/python-project.md) — Ruff, pytest, pip-audit, and optional type checks.
3. [TypeScript project](tutorials/typescript-project.md) — ESLint, Prettier, Vitest, npm audit, and TypeScript.
4. [Mixed-language project](tutorials/mixed-language-project.md) — deterministic multi-engine aggregation.
5. [Before a pull request](tutorials/before-a-pull-request.md) — a repeatable local quality gate.
6. [Connect an AI coding assistant](tutorials/ai-coding-assistant.md) — local stdio MCP.
7. [Add Rush to CI](tutorials/ci-integration.md) — bounded engines rather than every runtime.
8. [Team adoption](tutorials/team-adoption.md) — trial, policy, ownership, and rollout.

If you need lookup rather than a lesson, use the [CLI reference](reference/cli-reference.md).
