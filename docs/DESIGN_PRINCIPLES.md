# Design principles

1. One shared implementation for CLI and MCP.
2. Safe, local, non-mutating defaults.
3. Optional external engines; no implicit installation.
4. Structured, deterministic, redacted results.
5. Honest maturity and explicit missing evidence.
6. Explicit consent for browser, slow, network, fuzz, baseline, Git, and release effects.
7. Fixture-first engine compatibility and bounded CI.
8. Git-root-bounded configuration.
9. User documentation by goals; developer documentation by contracts.
10. No model/privacy claims beyond verified implementation.
