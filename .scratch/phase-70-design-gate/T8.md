## 1. Required behavior (testable statements)

**B1 — CLI anchor.**
- CLI relative input is joined once, lexically, to the invocation-start cwd.
- That cwd is `os.getcwd()`, captured at command entry. It is already physical (probe: `chdir` through a link, then `getcwd()` returned the real path).
- No `normpath`, `abspath` or `resolve` is applied before the walk.

**B2 — MCP anchor.**
- MCP relative input is joined to the declared root when `project` (or an existing `project_id`) is supplied.
- Otherwise it is joined to the server-start cwd, captured once in `build_server` (`mcp.py:41-78`).
- A process `chdir` after `build_server` changes nothing for:
  - standard, custom path/file/target and request-dict tools;
  - relative declared-project values;
  - cwd-relative secondary arguments (§3.8);
  - custom helper roots (§3.7).

**B3 — Spelling equivalence.** From the same anchor, these spellings of the same target give identical results (selection, context, error type and message):
- relative;
- absolute physical;
- absolute through a link that leads to the anchor or one of its ancestors (e.g. `/var/...` for `/private/var/...`, or a `$PWD` spelling through `~/code -> /data/code`);
- `a/../a/x` over real directories.

**B4 — Root precedence (§3.2).** Declared registered root, then the deepest marked-or-registered directory on the no-follow walk, then the deepest existing directory (the requested directory, or the file's parent, or the nearest existing ancestor of a missing path). A directory is marked only if one of these holds (all checked with `lstat`, never following):
- `rush.toml` is a regular file;
- `.rush` is a real directory and `.rush/project.json` is a regular file;
- `.git` is a directory or a regular file (worktree).

Symlinked markers are not markers. A symlinked `.rush` is never traversed.

**B5 — Symlink contract** (decision 3, 5.1, §5 R1). The link classes L1–L4 are defined in §3.2.
- Links above the logical root are transparent.
- A link met after a project is established is INTERNAL and rejected, except the L2 anchor-alias case.
- An in-anchor link met before any project is established is a root entry only when its destination is a marked or registered project root.
- An out-of-anchor, unestablished link to a directory is a transparent translation.
- A link to a file is never transparent.
- Dangling links and loops are rejected.
- Codes: `SYMLINK_DISALLOWED`; `REPARSE_POINT_DISALLOWED` for non-symlink reparse points; `PARENT_TRAVERSAL_DISALLOWED` for `..` after a link.

**B6 — Zero outside effects on rejection.** On any rejection:
- no `open` of any file;
- no config read, no target hash, no handler call, no registration, seed or suite step;
- no marker probe or `lstat` of any descendant of the rejected link.

An L1 rejection touches nothing through the link at all. L3 may probe only the destination directory's own three marker names (5.1 requires that). L2 and L4 may touch only the destination path itself via `realpath`.

**B7 — `..` handling (5.4).** `..` is processed per component during the walk:
- after a real directory it pops that directory;
- after a link (the frame entered via a link) it is rejected with `PARENT_TRAVERSAL_DISALLOWED`;
- inside a missing tail it stays in the suffix and containment rejects it.

**B8 — Ordering.** Walk → containment pre-check (`PhysicalRoot(root).open_contained(suffix)`) → config read (CLI and MCP only) → `resolve_invocation` (containment + hash) → handler. `resolve_target` has no `resolve()` fallback.

**B9 — Original request data.**
- `InvocationContext.original_requested_targets` holds the verbatim input strings (redaction applies only to diagnostics).
- It is `None` when unavailable: omitted MCP path, Click-defaulted CLI path, `rush ui` with no paths, scan candidates without an override.
- `invocation_start_cwd` is the anchor used (CLI cwd, MCP server-start cwd, suite anchor). `declared_root` is set when a root was declared.
- Normalized `PhysicalTarget`s, `ordered_args` and the config digest are identical across the B3 spellings.

**B10 — Scan staging.** Staging substitution stays execution-only (`project_run._execute_candidate`, `project_run.py:~780-805`). Originals are captured before staging.

**B11 — Declared root argument (decision 1, 5.2).**
- Exactly one declared-root argument per path-taking tool: `project` on the 52 catalog tools, the 11 custom path/file/target tools (including `rush_test_heal`) and `rush_attest_generate`; `project_id` kept on `rush_continuity` and `rush_memory`.
- It is optional and its schema description states the §3.2 rule.
- An injected `project` is never forwarded to a tool that lacks it.
- Routing is ID first, then path anchored to the server-start cwd. There is exactly one registry read per call.
- Named errors: `PROJECT_NOT_FOUND` (including empty value), `PROJECT_ROOT_MISSING`, `AmbiguousRootError` (target not under the root), `ScopeWideningError` (link below the root).

**B12 — Registered root is the logical root and dispatch authority** (5.1, 4c, 4d).
- `dashboard_cmd` walks once, rejects before `register_project`, registers the walk's canonical target, then uses `Path(record.root)` everywhere.
- TUI `plan_scan`/`rescan_project_run` and scan already dispatch on `Path(record["root"])`. No code change is needed there.

**B13 — `ui_cmd`.**
- Walks each input once (no paths: the cwd, original `None`) in place of `p.resolve()` at `cli.py:1061`.
- A rejection exits 2 before any seed or suite.
- Seeds carry the canonical target as `root`, plus `lexical_path` and `original_input`.
- The interactive initial check and the `--json` branch both run the suite on the lexical path with the original (4b).

**B14 — Suites.**
- CLI suite sites pass the typed path, the anchor and the original.
- `run_workflow_suite` walks exactly once per run and reuses the selection for every step.
- A walk failure becomes one error child per step (`fail_fast` stops after the first) and zero handler calls.

**B15 — Custom `file`/`target`.** These parameters are contained exactly like `path`. The handler receives the canonical contained absolute path. (At base they bypassed containment: `resolver._resolve_targets` at `resolver.py:153-159` reads only `path`/`files`/`paths`.)

**B16 — `_anchor` root for custom helpers (5.3, extended in §5 R4).**
- `TestHealer`'s root is the declared root, else the server-start cwd.
- The same `_anchor` is passed to `HalluGuard`, `BlastRadiusAnalyzer`, `ComplexityDecomposer`, `TypeSynthesizer` and `MeshLockManager`.
- `_anchor`/`project_root` never appear in any schema.

**B17 — Request-dict tools.** `rush_project`, `rush_scan` (including cancel/resume), `rush_scan_handoff` and `rush_agent_connection` anchor their path-bearing request fields to the server-start cwd:
- project references use ID-first routing;
- UUID-only ops (select, relink, configure `project`) are untouched.

**B18 — Error representation per transport:** see §3.6.

**B19 — No silent fallbacks.** No broad `except` in either wrapper. `OSError` (e.g. `PermissionError`) propagates unchanged.

**B20 — Server instructions.** `build_server_instructions` states the §3.2 rule for `project` and `project_id`.

### 3.1 Types and helpers (`src/rush/invocation/targets.py`)

```python
@dataclass(frozen=True)
class RootSelection:
    root: Path            # logical root: physical dir; declared -> Path(registry root string)
    relative: Path        # link-free root-relative suffix; Path(".") when target == root
    target: Path          # root / relative
    lexical: Path         # Path(raw) if absolute else anchor / raw  (pathlib: '..' kept; '.', '//', trailing '/' dropped)
    anchor: Path
    declared_root: Path | None

def registered_root_index(data_root: Path | None = None) -> dict[str, str]:
    from rush.setup.provision import DataRootUnavailableError
    from rush.workflows import projects as _projects
    try:
        base = data_root or _projects.default_data_root()
    except DataRootUnavailableError:
        return {}                       # §5 R10
    reg = _projects._load_registry(base)
    return {pid: str(e["root"]) for pid, e in reg["projects"].items()
            if isinstance(e, dict) and e.get("root")}
    # never list_projects()/resolve_project(): _project_view -> inspect_capabilities
    # reads every project tree (projects.py:253-256)

def route_project_reference(value: str, *, anchor: Path, index: Mapping[str, str]) -> tuple[str, Path]:
    if not isinstance(value, str) or value == "":
        raise ProjectNotFoundError(_redact(f"no registered project matches: {value}"))
    if value in index:                                   # ID first (IDs may contain "/")
        return value, Path(index[value])
    p = Path(os.path.expanduser(value)) if value.startswith("~") else Path(value)
    if not p.is_absolute():
        p = anchor / p                                   # server-start cwd, never live cwd
    canonical = str(p.resolve())                         # registry contract: _canonical_root
    for pid, root in index.items():
        if root == canonical:
            return pid, Path(root)
    raise ProjectNotFoundError(_redact(f"no registered project matches: {value}"))

def anchor_path_value(value, anchor):   # request path fields and cwd-relative args
    if not isinstance(value, str) or not value or value.startswith("~") or os.path.isabs(value):
        return value
    return str(anchor / value)

def anchor_project_value(value, anchor, index):
    return value if isinstance(value, str) and value in index else anchor_path_value(value, anchor)

def assert_contained(sel: RootSelection) -> None:
    try:
        PhysicalRoot(sel.root).open_contained(sel.relative, purpose="read")
    except ContainmentError as exc:
        raise ScopeWideningError(str(exc)) from exc      # same translation as targets.py:92-93

def assert_root_config_not_linked(root: Path) -> None:
    try:
        PhysicalRoot(root).open_contained("rush.toml", purpose="read")   # missing -> no error
    except ContainmentError as exc:
        raise ScopeWideningError(str(exc)) from exc

def select_member(raw, *, anchor, root, index) -> Path:   # for `files` / `paths` lists
    try:
        return select_root(raw, anchor=anchor, declared_root=root, index=index).relative
    except AmbiguousRootError:
        raise UndeclaredInputError(_redact(f"External host input '{raw}' is outside workspace root '{root}'")) from None
```

`_redact(s) = sanitize_value(s).value` (`rush/safety/redactor.py:52`). Probe: ordinary paths and UUIDs come back unchanged; `ghp_…` becomes `[REDACTED_GITHUB_TOKEN]`.

### 3.2 The no-follow root walk

```python
REPARSE = getattr(stat, "FILE_ATTRIBUTE_REPARSE_POINT", 0x400)
def _is_link(st): return stat.S_ISLNK(st.st_mode) or bool(getattr(st, "st_file_attributes", 0) & REPARSE)
def _ident(st): return (st.st_dev, st.st_ino)

def _has_marker(d: Path) -> bool:                       # lstat only; OSError -> not a marker
    s = _lstat_or_none(d / "rush.toml")
    if s and stat.S_ISREG(s.st_mode): return True
    s = _lstat_or_none(d / ".rush")
    if s and stat.S_ISDIR(s.st_mode) and not _is_link(s):
        s2 = _lstat_or_none(d / ".rush" / "project.json")
        if s2 and stat.S_ISREG(s2.st_mode): return True
    s = _lstat_or_none(d / ".git")
    return bool(s and not _is_link(s) and (stat.S_ISDIR(s.st_mode) or stat.S_ISREG(s.st_mode)))

@dataclass
class _Frame:  path; ident; marked; registered; established; in_anchor; via_link: Path | None

def select_root(raw, *, anchor, declared_root=None, index=None) -> RootSelection:
    raw = str(raw)
    index = registered_root_index() if index is None else index
    roots = frozenset(index.values())
    lexical = Path(raw) if Path(raw).is_absolute() else anchor / raw
    comps = lexical.parts
    bounded = anchor.parent != anchor                    # §5 R1(v): filesystem/drive root bounds nothing
    a_id = _ident(os.stat(anchor))
    anc_ids = {_ident(os.stat(q)) for q in (anchor, *anchor.parents)}
    r_id = _ident(os.stat(declared_root)) if declared_root is not None else None

    def frame(p, st, parent, via=None):
        marked = _has_marker(p); reg = str(p) in roots
        est = (parent.established if parent else False) or marked or reg or _ident(st) == r_id
        ina = bounded and ((parent.in_anchor if parent else False) or _ident(st) == a_id)
        return _Frame(p, _ident(st), marked, reg, est, ina, via)

    def ancestry(dest, via):                             # dest is physical (realpath strict)
        fs = [frame(Path(dest.parts[0]), os.lstat(dest.parts[0]), None)]
        for name in dest.parts[1:]:
            q = fs[-1].path / name; st = os.lstat(q)
            if _is_link(st) or not stat.S_ISDIR(st.st_mode):
                raise scope("SYMLINK_DISALLOWED", f"Symlink at component '{via}' cannot be resolved: destination changed during resolution")
            fs.append(frame(q, st, fs[-1]))
        fs[-1].via_link = via
        return fs

    def project_of(fs):  # deepest frame that establishes a project
        return next(f.path for f in reversed(fs) if f.marked or f.registered or f.ident == r_id)

    def scope(code, msg):
        return ScopeWideningError(_redact(str(ContainmentError(code, msg, raw))))
        # renders "[CODE] at '<raw>': <msg>"

    def dest_of(p, code):
        try: return Path(os.path.realpath(p, strict=True))
        except OSError as exc:  # dangling -> FileNotFoundError; loop -> OSError errno 62 (probed)
            raise scope(code, f"Symlink at component '{p}' cannot be resolved: {exc.strerror}") from None

    frames = [frame(Path(comps[0]), os.lstat(comps[0]), None)]
    tail: list[str] = []
    alias_guard: tuple[Path, Path] | None = None
    for i in range(1, len(comps)):
        c, top = comps[i], frames[-1]
        if c == "..":
            if top.via_link is not None:
                raise scope("PARENT_TRAVERSAL_DISALLOWED", f"'..' after symlink component '{top.via_link}' is forbidden")
            if len(frames) > 1: frames.pop()
            continue
        p = top.path / c
        try: st = os.lstat(p)
        except (FileNotFoundError, NotADirectoryError):
            tail = list(comps[i:]); break            # other OSError (e.g. PermissionError) propagates
        if _is_link(st):
            code = "SYMLINK_DISALLOWED" if stat.S_ISLNK(st.st_mode) else "REPARSE_POINT_DISALLOWED"
            if top.established and top.in_anchor:                                   # L1 INTERNAL
                raise scope(code, f"Symlink detected at component '{p}' inside project '{project_of(frames)}'")
            d = dest_of(p, code)
            if top.established:                                                     # L2 (outside anchor)
                if d.is_dir() and _ident(os.stat(d)) in anc_ids:
                    alias_guard = alias_guard or (p, project_of(frames))
                    frames = ancestry(d, p); continue
                raise scope(code, f"Symlink detected at component '{p}' inside project '{project_of(frames)}'")
            if top.in_anchor:                                                       # L3 ROOT ENTRY
                if d.is_dir() and (_has_marker(d) or str(d) in roots):
                    frames = ancestry(d, p); continue
                raise scope(code, f"Symlink at component '{p}' is not a project root entry: '{d}' is not a marked or registered project root")
            if d.is_dir():                                                          # L4 translation
                frames = ancestry(d, p); continue
            raise scope(code, f"Symlink detected at component '{p}': a symlinked file is never transparent")
        if stat.S_ISDIR(st.st_mode):
            frames.append(frame(p, st, top)); continue
        tail = list(comps[i:]); break                      # file (or file/more -> later ENOTDIR = missing)
    if alias_guard is not None and not frames[-1].in_anchor:
        link, proj = alias_guard
        raise scope("SYMLINK_DISALLOWED", f"Symlink detected at component '{link}' inside project '{proj}'")
    if declared_root is not None:
        j = next((k for k, f in enumerate(frames) if f.ident == r_id), None)
        if j is None:
            raise AmbiguousRootError(_redact(f"registered root '{declared_root}' does not contain requested target '{raw}'"))
        root = declared_root
    else:
        marks = [k for k, f in enumerate(frames) if f.marked or f.registered]
        j = marks[-1] if marks else len(frames) - 1
        root = frames[j].path
    names = [f.path.name for f in frames[j + 1:]] + tail
    relative = Path(*names) if names else Path(".")
    return RootSelection(root, relative, root / relative, lexical, anchor, declared_root)
```

**Why each link class is safe.**
- L3 is exactly 5.1: the destination itself must be a marked or registered project root.
- L4 and L2 translations are equivalent to typing the destination's physical path, which is accepted anyway, so they add no reach.
- L1 is the only case where following would cross an established project boundary, and it rejects without touching the destination.

### 3.3 Root selection and prefix translation

- **Above-root prefix translation.** It is exactly the L2/L4 ancestry rebuild. Everything after the translation is walked no-follow from the destination's physical ancestry. `in_anchor` and `established` are recomputed by physical identity.
- **Declared/registered roots.** The root must appear as a frame by `(st_dev, st_ino)`. This replaces RT2's whole-path `realpath` precheck (`targets.py:85` RT2):
  - an unrelated target raises `AmbiguousRootError`;
  - a lexical descendant through a link below R raises `ScopeWideningError` (L1);
  - an alias spelling of R is accepted.
- **Nearest marker.** The root is the deepest marked or registered frame. A `registered` frame matches a registry root string by equality, the same rule `resolve_project` uses (`projects.py:489-491`); registered roots normally also carry the `.rush/project.json` descriptor.

### 3.4 Containment, config and read ordering

For the CLI and MCP boundaries:
1. `select_root`.

6. `resolve_invocation` (containment + hash, `targets.py:91-...`).

## 5. Resolutions (decision + justification)

**R1 — The orchestrator's absolute-input rule.** Validated case by case in the table below. Five corrections:
- **(i)** "Lexically under the anchor" must become "some prefix of the input is the anchor by `(st_dev, st_ino)` identity". This is realized through L2/L4 translation plus the `in_anchor` identity check. With lexical matching, `/var/…/T/nomark/out/s.py` from anchor `T` (physical `/private/var/…/T`) falls to rule (3) and is **accepted**, while `nomark/out/s.py` is **rejected**. That violates the rule's own "identical outcomes".
- **(ii)** "Nearest marked or registered ancestor" must be computed top-down with no-follow classification (L1/L2). Computed by probing lexical ancestors, `proj/vendor/pkg/secret.py` selects `pkg` (through `vendor`), which is the Codex escape.
- **(iii)** A final-component **directory** link outside the anchor with no project established is translated (it is the root's own alias, so it sits at or above the root under decision 3). Literal rule (3), "final component checked no-follow", falsely rejects `rush check /abs/alias-to-dir`. A final **file** link is always rejected.
- **(iv)** L2: a link met outside the anchor after a project is established is transparent only when its destination is the anchor or an ancestor of it **and** the walk then reaches the anchor. Otherwise it is INTERNAL. Without this, an absolute `$PWD` spelling (`/Users/x/code/proj/src/a.py`, where `~/.git` exists and `code -> /data/code`) is falsely rejected; with no guard, in-project links not leading to the anchor would be accepted, against decision (3).
- **(v)** An anchor that is a filesystem or drive root (`anchor.parent == anchor`) bounds nothing: `in_anchor` stays false, so L4 applies. Otherwise an MCP server whose cwd is `/` sees `/var` and `/tmp` as in-anchor, unestablished links to unmarked directories and rejects every macOS temp path. Decision (3) names `/var` as transparent.

**Validation table.** Layout: `T` = `tmp_path.resolve()/w`; `proj` (marked, registered); `proj/vendor -> otherrepo` (marked); `otherrepo/pkg/.git`; `nomark/out -> unmarked`; `alias -> proj`; `above -> T` (a `/var`-style alias); `U` = unrelated anchor.

| Case | rel from `T` | abs physical from `T` | abs alias from `T` | from `U` | from anchor `proj` / `nomark` |
|---|---|---|---|---|---|
| `proj/vendor/x` | reject L1 | reject L1 | reject L1 | reject L2 | `vendor/x`: reject L1 |
| `proj/vendor/pkg/secret.py` | reject L1, `pkg` never probed | same | same | reject L2 | reject L1 |
| `nomark/out/s.py` | reject L3 | reject L3 | reject L3 (identity) | accept, root `unmarked` (L4; no boundary exists) | `out/s.py` from `nomark`: reject L3 |
| `nomark/out/sub/s.py` | reject L3, `sub` never probed | same | same | accept, root `unmarked/sub` | reject L3 |
| `alias` (dashboard/ui/check) | accept, root `proj` (L3) | same | same | accept (L4 then marker) | n/a |
| `/var`-alias `proj/src/a.py` | n/a | n/a | accept | accept (L4) | accept (L2 guard satisfied) |
| `/var`-alias no-marker file | n/a | n/a | accept, fallback parent | accept | accept |

**R2.** An in-anchor link to an **unmarked** directory whose subtree contains a marked project (e.g. `~/code -> /Volumes/x/code`, run from `~`) is rejected. This is 5.1 literal. Checking the subtree would probe descendants of a link that is then rejected, violating "zero descendant marker probes" (Codex matrix item 5). Recovery: run from inside the project (physical anchor), use the physical path, or declare the root.

**R3.** Secondary arguments follow §3.8. Only cwd-relative ones are anchored; root-relative ones keep their tool contracts (anchoring them would break tools that reject absolute values). This is the full-scope reading of §3.2 "MCP relative input" and decision (1)'s schema promise.

**R4.** `_anchor` is applied to all six helper constructors, not only `TestHealer`. A published `project` that does not move their internal root would be a no-op, and `project` would be a false promise for `rush_blast_radius` (importer scan) and `rush_mesh_*` (lock containment).

**R5.** Project references are routed ID first, then as a path anchored to the server anchor. This mirrors `resolve_project`'s ID-first order (`projects.py:164-166`) and fixes bare names and IDs containing "/".

**R6.** Config is read from the selected root only after containment. A symlinked root `rush.toml` is rejected: it lies inside the root (decision 3). Ancestor discovery above the root is unchanged (transparent zone). Suites keep `config=None`.

**R7.** Error representation is as in §3.6. CLI exit 2 follows §3.2 and the `RushConfigError` precedent. T9 keeps ownership of the missing-target → error mapping; T8 still reports missing targets as `deleted`, as at base.

**R8.** The originals field is `tuple[str, ...] | None`, with `None` meaning unavailable. A Click-defaulted path is detected with `ParameterSource.DEFAULT`, so it is never reported as user input.

**R9.** An empty declared project gives `PROJECT_NOT_FOUND`. A missing declared root directory gives `PROJECT_ROOT_MISSING` (`projects.py:98-101`).

**R10.** `DataRootUnavailableError` produces an empty index for undeclared walks: no registration can exist where no data root resolves, because `register_project` uses the same function (`projects.py:290`). It propagates for explicit `project` routing.

**R11.** A wrapper built without `anchor_cwd` uses the live cwd per call. `tests/test_mcp.py:531-537` (register, then `chdir`, then `wrapper()`) depends on this. `build_server` always passes its captured anchor, and that is asserted.

**R12.** Removing the `resolve_target` fallback breaks nothing. Experiment: the c78e445 full suite with `targets.py:81` replaced by an instrumented `raise`. Results: 2760 passed, 3 skipped. Fallback hits came only from `tests/test_phase57_physical_scope.py::test_undeclared_host_input_refuses`, which expects `UndeclaredInputError` either way. The 5 failures were environmental:
- 2 in `tests/test_phase52_installed_artifacts.py`: no `dist/`;
- 3 in `tests/test_dashboard_scan_actions.py`: `started.wait(5)`, reproduced flaky on c78e445 (1 of 2 runs failed each on base and on the experiment) while another full-suite run was active.

**R13.** No concurrent-adversary (TOCTOU) resistance is claimed. The design is pathname-based, like Phase 55 `PhysicalRoot`; the plan's constraints do not require it; containment is re-checked immediately before reads. No swap tests.

**R14.** TUI `_run_check_suite` re-walks the lexical path, per (4)(b). 5.1's "never re-resolved" sentence governs the registry-dispatched routes (dashboard, TUI scan and rescan, scan).

**R15.** The `ui --json` branch uses the same lexical path and original as the interactive branch.

**R16.** A `..` that pops above the anchor leaves in-anchor classification. Outcomes stay identical to the equivalent absolute path.

**R17.** Registry matching is by string equality, exactly as in `resolve_project`.

**R18.** For targets, `~` stays literal (base semantics). For project references it is expanded (`_canonical_root` contract).

**R19.** A symlinked `.git`, `.rush` or `rush.toml` is not a marker, and `.rush/project.json` behind a linked `.rush` is never probed.

**R20.** `project_id` values are routed as the declared root and forwarded unchanged (decision 1).

**R21.** Windows junctions are handled through the reparse attribute (`REPARSE_POINT_DISALLOWED`). They are tested by injecting `lstat` results, so no test is skipped.

**R22.** `PermissionError` propagates; there is no anchor fallback.
