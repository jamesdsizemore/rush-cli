# Alternatives and complements

Run Ruff, ESLint, pytest, or scanners directly when you need their full configuration, native output, fix modes, or latest features. Use pre-commit for repository hook orchestration, CI platforms for remote job execution, and dedicated security/SAST products for deeper coverage.

Rush's value is one safe, consistent local/CI/assistant interface across selected existing tools. It complements rather than replaces them. Graft complements Rush by adding optional local code context; Rush asks “what quality evidence exists?” while Graft helps answer “how is this code connected?”
