# Agentic Rush/Anti Hallucination

## Anti-Hallucination Guardrails (Phase 43)
* **Static Import Verification**: `rush hallu-guard` validates AST imports.
* **Mistake Miner**: `rush context mistakes` loads bi-temporal Git revert history.
* **Failure Ledger**: Blocks re-execution of previously failed patch fingerprints.
* **Continuity receipt**: exposes a redacted failure receipt or a tombstone and labels historic instruction as quarantined evidence, preventing a resumed agent from inventing authority from old context.
