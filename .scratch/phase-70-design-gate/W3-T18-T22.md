### 3. Design
- **Root.** `root = resolve_logical_root(Path(os.path.abspath(Path.cwd())))`, T8's function with the ROOT-ENTRY rule (T8 decision 5.1).
  - If `resolve_project(root)` succeeds, use its canonical `record["root"]`; otherwise use `Path(root).resolve()`.
  - A T8 rejection (internal symlink / AmbiguousRootError) → E_INPUT, exit 2.
  - Canonical identity = `str(canonical_root)`.
- **`open_readonly` (G1 fix).** If `db` is missing → `available=False` with zero I/O (unchanged). Otherwise:
  - `-wal` and `-shm` both exist → `?mode=ro` (a transactional snapshot that works alongside a live writer).
  - Neither exists → `?mode=ro&immutable=1`, recording `fingerprint = (st_ino, st_size, st_mtime_ns)` of `memory.db`.
  - `-wal` without `-shm` → `available=True, connection=None, state="wal_index_missing"`.
  - Keep the existing `migration_required` rule.
  - `unchanged()` returns True when no `-wal` has appeared and the fingerprint is equal.
- **Read algorithm (one connection).**
  1. `BEGIN`.
  2. `PRAGMA table_info(memory_artifacts)` → select only the columns that exist; missing `archived_at`/`expired_at` → NULL; missing owner columns → legacy owner.
  3. `gen = store_generation(conn)`.
  4. Token validation (below).
  5. Count with `WHERE archived_at IS NULL AND expired_at IS NULL [AND source NOT IN (...)]`.
  6. Page with `ORDER BY created_at DESC, id DESC LIMIT 20 OFFSET ?`.
  7. `hidden_internal` count when not `include_internal`.
  8. `COMMIT` and close.
  9. If immutable and `not unchanged()` → retry, up to 3 attempts total. Still changing → `E_STORE_BUSY` (error, exit 2), no rows.
  - `sqlite3.DatabaseError` → `E_STORE_CORRUPT`.
- **Token.** base64url, unpadded, of `json.dumps({"v":1,"root":<canonical>,"generation":<int>,"filters":{"include_internal":<bool>},"limit":20}, sort_keys=True, separators=(",",":"))`.
  - Validation order:
    1. decode/JSON — `malformed_token`;
    2. exact keys and types (bool ≠ int, generation ≥ 0) — `malformed_token`;
    3. root — `project_mismatch`;
    4. filters/limit — `filter_mismatch`;
    5. inside the read transaction, generation — `stale_generation`.
  - Steps 1–4 run before any DB open.
  - `offset > 0` and no token → `token_required`, with no DB open.
  - A token supplied at offset 0 is validated too.
  - Every OK page returns a fresh token for the current generation, plus `next_offset` (null at the end).
  - An offset past the end → ok, `rows: []`, `next_offset: null`.
- **Envelope `raw.data`.** `{project_root, total, offset, limit:20, include_internal, rows, next_offset, generation_token, hidden_internal?, reason?}`.
  - Error envelopes: `{message, reason, restart:{offset:0}}`.
  - `metadata.operation="overview"`. No `metadata.memory` (R20.5).
- **Human output (plain lines, no color dependence).**
  - `memory: {total} useful record(s) in {root} (showing {a}-{b})`.
  - One line per row: `id  subject  source  owner kind:id  ISO-8601 UTC  trust`.
  - `next: rush memory --offset {n} --generation {token}`.
  - The empty reason line. Exit via `exit_code_for`.
