# Support

Before asking for help, collect the Rush version, platform, exact command, target type, JSON result, engine version, and redacted stderr logs. Search [Troubleshooting](user-guide/troubleshooting.md), [Matrix](TROUBLESHOOTING_MATRIX.md), and [FAQ](user-guide/faq.md).

Never include API keys, credentials, private source, or raw secret values in a public report.
