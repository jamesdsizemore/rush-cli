# Product scope

Rush is a Python CLI and local stdio MCP server for consistent code-quality, test, dependency, supply-chain, project-file, and local workflow evidence. It routes to optional installed engines and returns canonical results.

Out of scope: network daemon/API, implicit installers, universal scanner marketplace, autonomous remediation, full sandboxing, human-review certification, working model review, Git history mutation, remote CI control, release publication, and unbounded browser/network/load execution.

Current tool maturity is authoritative in [Tool catalog](TOOL_CATALOG.md).
