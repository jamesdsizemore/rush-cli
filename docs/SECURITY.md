# Security

Rush's user-facing controls are documented in [Safety](safety/safety-overview.md) and [Security model](safety/security-model.md). Report vulnerabilities privately through the repository host's security-reporting mechanism when available; do not open a public issue containing credentials, exploit details, private source, or unredacted scanner output.

Maintainers follow [Incident and security](maintainers/incident-and-security.md).
