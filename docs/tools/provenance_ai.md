# AI Code Provenance Auditor (`rush provenance-ai`)

## Overview
`rush provenance-ai` audits AI code attribution and provenance across Git commit history. It inspects commit trailers (`Co-authored-by:`, `Generated-by:`, `Model:`, `Agent:`, `AI-Assisted:`), identifies shallow clone depth, and deterministically reports 30/60/90-day survival states without ungrounded causal claims per ADR-0036 and D50-12.

## Classification
- **Category**: `workflow`
- **Maturity**: `real_adapter`
- **Tool Name**: `provenance-ai`
- **FastMCP Tool**: `rush_provenance_ai`

## Capabilities
1. **Commit Trailer Attribution**: Parses standard Git trailers to classify commits into:
   - `ai_generated`: Commits created directly by AI agents or marked with `Generated-by:` / `Agent:`.
   - `ai_assisted`: Commits with `Co-authored-by:` naming an AI entity, or tagged with `Model:` / `AI-Assisted:`.
   - `human`: Commits authored solely by human contributors with no AI trailers.
2. **Shallow History Detection**: Inspects `.git/shallow` and Git repository depth. If the clone is shallow, emits a warning finding indicating that historical provenance is truncated.
3. **Deterministic Survival & Defect States**: Per Decision Record D50-12 (PR50.0.5), survival and defect correlation are explicitly reported as `unknown` states to prevent hallucinations or unsubstantiated zero-defect claims:
   ```json
   "survival_states": {
     "30d": "unknown",
     "60d": "unknown",
     "90d": "unknown",
     "reason": "Deterministic baseline: line lifecycle causal analysis deferred"
   }
   ```
